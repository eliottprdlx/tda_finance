# Topological data analysis for financial time series

Python implementation and additional research based on the papers :

- Marian Gidea and Yuri Katz. “Topological data analysis of financial time series: Landscapes of crashes”. In: Physica A: Statistical Mechanics and its Applications 491 (2018), pp. 820–834. DOI: 10.1016/j.physa.2017.09.028
- A. Aguilar and K. Ensor. “Topology Data Analysis Using Mean Persistence Landscapes in Financial Crashes”. In: Journal of Mathematical Finance 10.04 (2020), pp. 648–678. DOI: 10. 4236/jmf.2020.104038.
